## 本文研究了什么？
研究如何让已训练的神经参数化仍可在宿主模式中校准。本文有L63和L96试验；这里关注L96只替代小尺度耦合项、保留大尺度动力学的部分，作为模块级方法参考。

先跨物理参数范围训练条件网络，再冻结网络权重，通过宿主长期统计校准少量输入参数；用高斯过程近似有噪声的校准目标。并非将长时间序列反传以更新全部神经权重。

理想试验能找回接近参考的参数；有意扰动另一个宿主参数后，调节网络输入也能改善长期统计，但最优值偏离原参考参数。这显示统计校准与物理参数恢复可能分离。

## 有哪些局限或隐含问题？
已读主文，未复现补充代码。作者明确将其定位为玩具系统验证，承认扩大训练参数范围会增加成本，真实气候模式仍待检验。其长期统计来自模拟，不是月年沉降现场观测。

## 对我的研究有什么用，哪里不同？
可先冻结已能逼近CMAQ的网络，保留少数有物理意义的阻力修正或通道系数作为条件输入；用真实站点和窗口算子生成模拟月累计/平均观测，在宿主外层做低维校准。先检查现有网络是否能表示这些参数变化；若训练只覆盖固定参数，需补采样训练，不能任意附加新输入。低维目标可试高斯过程辅助搜索，减少整段CMAQ调用。

**差异与迁移前提**

本文校准的是显式物理输入，不是数十万网络权重；其均值/标准差目标也不是累计质量。你的目标须用真实时间积分、采样缺口与空间支持算子替换，并给出误差模型。论文仅支持一种可行设计思路，不证明月年数据足以识别瞬时Vd或所有交换通道。
