## 本文研究了什么？
研究如何让一个遥感编码器同时保留局部差异和整体模式，兼容多模态、单时相及多时相输入。它是地表输入表示方法，不是CMAQ或沉降过程的端到端替代。

以局部和整体两个自监督目标学习不同层次的特征；用不同模态和形状的数据做分类、分割、像元时序任务，并比较冻结特征和微调方案。

消融表明整体目标与局部目标各有偏向，组合有助于兼顾不同任务；其多任务优势不表示每个数据集、模型尺寸都最优，也不证明对沉降通量有增益。

## 有哪些局限或隐含问题？
核对ICML/PMLR摘要及arXiv v3的输入、实验、消融段落，未通读全文或复现，保守标速读。主要证据来自遥感基准；不能据此断言具备分钟级过程信息或CPU上线提速。

**隐含问题分析（阅读者推断）**

阅读者推断：该预训练体系能接收天气和TerraClimate ET、土壤水等派生产品。若你在通量实验中也加入这些量，收益可能来自新增过程信息，而不仅是编码器更好；应区分预训练接触过某模态与推理实际输入了某模态。用相同公共输入比较AEF/时序表征，再单独加入派生产品，检查时间可用性和验证独立性。这里指出的是公平对照要求，不是指称本文沉降实验存在泄漏——它没有做这种实验。

## 对我的研究有什么用，哪里不同？
以冻结编码器加同一轻量过程头做输入消融：常规地表变量、现有AEF、局部特征、整体时序特征以及二者组合。通量塔训练可结合FFP匹配地表支持；聚合特征后预测与先预测细尺度通量再聚合一般不等价，应分别检验。慢变化特征可预计算，但要计入预处理、存储读取及更新频率成本。

**差异与迁移前提**

遥感分类/分割与过程系数学习的目标不同，多模态可用也不代表都应加入。不能以小样本分类成功推断月年观测能识别高频Vd。它值得作为表征对照与尺度实验来源，暂不构成更换你当前地表输入方案的直接证据。
