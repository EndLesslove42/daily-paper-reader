## 今日简报
今天选3篇可靠的非近期研究，围绕两个实际障碍：模块已经模拟准确，为什么嵌回后仍更慢；长窗口观测怎样约束参数并保留不确定性。两篇在线替代实验分别暴露低GPU利用率和跨进程场交换成本，另一篇提供不依赖CMAQ伴随的外层校准路线。它们均保留物理宿主，不是整模型端到端替代。建议先画CMAQ实测时间分解，再决定扩大替代边界、原位CPU部署或异构耦合；观测学习先从少量可辨识校准参数开始。
