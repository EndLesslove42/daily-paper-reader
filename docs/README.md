## 今日简报
今天聚焦三个可立即推进的问题：多份观测数量悬殊时该诊断什么；如何把沉降路径、浓度与累计通量分开核查；保留物理宿主后，怎样检验神经模块是否改善了未直接监督的过程。选入3篇较早文献：生态模型的合成校准实验、AQMEII4沉降诊断协议及可微水文模块学习。它们分别提供统计诊断、物理诊断接口和训练/验证范式；均不能单凭月均浓度拟合证明瞬时Vd或全部沉降路径已被识别。本期1篇正文精读、2篇速读。

## 精读区
1. [多份观测数量悬殊时，真正的问题是样本不平衡，还是模型与数据有系统偏差？](/202611/18/codex-dae89d47a4ff-issues-in-calibrating-models-with-multiple-unbalanced-constraints-the-signi) — 迁移建议：固定少量独立沉降观测，逐批加入浓度数据，分别画训练与留出误差，检查浓度越加越多时沉降检验是否变差。再比较无偏差项、有依据的来源偏差项和干扰模块扰动三组结果。模拟标签作为教师参考单独做权重消融；行数相等不能代替误差建模，来源不同也不等于误差独立。

## 速读区
1. [AQMEII4：把干湿沉降放回空气质量宿主，建立可比较的过程诊断](/202611/18/codex-c0e78c850746-technical-note-aqmeii4-activity-1-evaluation-of-wet-and-dry-deposition-sche) — 迁移建议：在原模型与替代模块中同步保留参考浓度、实际沉降通量、Vd及可获得的过程诊断，先按真实采样窗聚合通量，再对比观测，避免用月均浓度乘月均Vd冒充累计量。湿沉降联合检查同窗降水及雨水化学；另做其他模块扰动对照，区分固定宿主条件下的改进与对干扰误差的稳健性。
2. [保留物理宿主学习过程模块：只监督流量后，如何核查其他内部通量？](/202611/18/codex-c5c1001d5935-differentiable-learnable-regionalized-process-based-models-with-multiphysic) — 迁移建议：保留物理宿主，将观测算子置于模拟输出之后，让窗口浓度或累计通量参与损失；设置教师标签基线、加入不同实测来源及联合训练的消融。独立检验保留按站点和连续时段留出的数据，并检查未直接监督的物种/过程是否退化。先用低维适配探索可辨识范围，再逐步增加自由度。
