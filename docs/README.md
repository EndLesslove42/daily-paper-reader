## 今日简报
今日专题：月均、单点、稀疏观测怎样约束正确的沉降模块。三篇可靠的较早研究分别讨论月平均多物种浓度的互补约束、多来源观测之间的冲突，以及模型结构误差与物理参数的混淆。共同提醒：只开放沉降参数参与优化，不代表浓度或沉降残差就来自沉降；应先检验可辨识的参数组合，再扩大网络更新范围。本期均为速读，核对摘要并阅读相关正文，未声称阅读全文。

2. [多类稀疏气溶胶观测如何共同约束过程参数，以及何时产生冲突](/202611/17/codex-615c20cda9fc-robust-observational-constraint-of-uncertain-aerosol-processes-and-emission) — 下一步实验（迁移建议）：分别用浓度、独立干沉降、wet-only湿沉降约束同一小参数集合，再交叉预测其余数据。画出各数据源偏好的参数区间与联合可行区；若无法兼容，先定位冲突，避免通过一个总RMSE强行折中。数据合作优先补互补物种、同窗降水与采样元数据，而非仅增加同类行数。
3. [为什么观测拟合正确，物理参数仍可能错误：模型差异项与校准的混淆](/202611/17/codex-ed310272a6a1-learning-about-physical-parameters-the-importance-of-model-discrepancy) — 下一步实验（迁移建议）：将观测写成各自采样算子作用于宿主输出，加上有明确来源的误差项。先校准低维沉降改变量，并对排放、混合、降水等做扰动对照；原模拟标签保留为预训练或正则参考。只有通过这些检验，才逐步开放更多网络参数。教师权重和误差先验都须做敏感性分析。
